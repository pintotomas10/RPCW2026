13. Cria um query SPARQL que poduza uma distribuição dos doentes pelas doenças, ou seja, dá como resultado uma lista de pares (doença, nº de doentes);
PREFIX : <http://www.example.org/disease-ontology#>
SELECT ?doenças (COUNT(?paciente) AS ?numDoentes) WHERE {
    ?paciente a :Patient ;
             :hasDisease ?doenças .
}
GROUP BY ?doenças

14. Cria um query SPARQL que poduza uma distribuição das doenças pelos sintomas, ou seja, dá como resultado uma lista de pares (sintoma, nº de doenças com o sintoma);
PREFIX : <http://www.example.org/disease-ontology#>
SELECT ?sintoma (COUNT(?doenca) AS ?numDoencas) WHERE {
    ?doenca a :Disease ;
             :hasSymptom ?sintoma .
}
GROUP BY ?sintoma
ORDER BY DESC(?numDoencas)

16. Cria um query SPARQL que poduza uma lista das doenças e respetivos sintomas, ou seja, dá como resultado uma lista de pares (doença, lista de sintomas).
PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX : <http://www.example.org/disease-ontology#>
SELECT ?doença (GROUP_CONCAT(?nomeSintoma; separator=", ") AS ?listaSintomas) WHERE {
    ?doença a :Disease ;
             :hasSymptom ?sintoma .
    bind(strafter(str(?sintoma), "#") as ?nomeSintoma)
}
GROUP BY ?doença
ORDER BY ?doença
